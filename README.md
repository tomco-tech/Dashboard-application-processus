# Dashboard Applications — V4

Vue à trois niveaux :

1. **Applications** : consolidation par application ;
2. **Travaux** : demandes par service utilisateur et chantier de qualification en cours ;
3. **Détails** : lignes de flux ou détail des qualifications SSI et fonctionnelle.

Le widget corrèle `B_Applications`, `REF_Flux Applications` et `REF_Applications Qualifiées`. Il nécessite `Full document access`.
